# 【全民健康管理】骨折突发别慌！院外急救“黄金法则”，普通人也能学会

> 更新时间：2026-09-11 (UTC+8)

户外散步的老人突然摔倒、运动时不慎扭伤脚踝、儿童玩耍时意外骨折……生活中骨折意外随时可能发生，掌握院外骨折急救知识，能在第一时间减少损伤、为后续治疗争取机会。

**一、如何快速识别骨折？**

**出现以下表现，要警惕骨折可能：**

**•疼痛剧烈**：受伤部位疼痛明显，活动或按压时加剧；

**•肿胀畸形**：局部迅速肿胀，甚至出现肢体变形、异常弯曲；

**•活动受限**：受伤肢体无法正常活动，或出现“反常活动”（比如手臂骨折后，抬手时出现异常晃动）；

**•骨擦音/骨擦感**：移动受伤部位时，可能听到骨头摩擦的声音或感觉到摩擦感（非专业人士不建议主动尝试）。

**二、这些错误做法，千万别做！**

**错误1：盲目搬动，“越动越伤”**

骨折后随意搬动患者（比如脊柱骨折时抱、背患者），可能导致骨折断端移位，加重神经、血管损伤，甚至造成瘫痪。

**错误2：揉捏按摩，“雪上加霜”**

受伤后用力揉捏、按摩肿胀部位，会加重局部出血和组织损伤，让肿胀、疼痛更严重。

**错误3：自行复位，“好心办坏事”**

非专业人员尝试“正骨复位”，极易导致骨折断端二次损伤，增加后续治疗难度。

**错误4：忽视“小骨折”，延误治疗**

手腕、脚踝等部位的“轻微骨折”若不及时处理，可能发展为畸形愈合，影响肢体功能。

**三、院外骨折急救，正确步骤请记牢！**

**步骤1：止血（针对开放性骨折）**

若骨折部位有出血，立即用干净纱布或毛巾按压止血，避免使用止血带（易造成肢体缺血），若出血量大，可在医生指导下短暂使用止血带，并标记使用时间。

**步骤2：固定，“让骨头不再乱动”**

就地取材（木板、树枝、硬纸板、甚至杂志），将骨折肢体上下关节同时固定，固定物与皮肤之间垫上毛巾或衣物，避免压迫皮肤。

•上肢骨折：可将手臂固定于胸前，用三角巾或围巾悬吊；

•下肢骨折：用长木板从大腿根部固定至脚踝，避免肢体弯曲；

•脊柱骨折：严禁随意搬动，保持患者身体平直，等待专业救援。

**步骤3：搬运，“选对方式很关键”**

•肢体骨折：使用担架或硬板搬运，避免骨折部位受力；

•脊柱骨折：必须多人协作，保持患者身体整体平移，严禁扭曲、翻身，最好使用硬板床或脊柱板搬运。

**四、不同部位骨折，急救要点有区别**

**骨折部位**

**急救重点**

上肢骨折（手臂、手腕）

固定后悬吊于胸前，减少肢体晃动

下肢骨折（大腿、小腿、脚踝）

用长木板固定，避免行走、弯曲

脊柱骨折（颈椎、胸椎、腰椎）

严禁抱、背，保持身体平直，等待专业救援

**五、医生提醒：出现这些情况，立即送医！**

•开放性骨折（骨头外露）；

•骨折部位明显畸形、剧痛难忍；

•肢体麻木、发凉、颜色发紫（提示血管、神经损伤）；

•怀疑脊柱骨折，出现肢体瘫痪、大小便失禁等症状。

骨折急救是“与时间赛跑”的过程，掌握科学方法，才能最大限度减少损伤。
